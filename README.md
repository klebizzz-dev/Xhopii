# Desenvolvimento de uma interface web

Este projeto de interface foi desenvolvido na matéria eletiva de linguagem de programação IV, ministrada pelo professor Bruno Santos de lima. 




## Tecnologias Utilizadas

Foi usado no desenvolvimento desse projeto:

- HTML5
- CSS3
- JavaScript
- Bootstrap (apenas no carrossel)

O projeto foi utilizado para o aprimoramento do uso do software de versionamento GIT, e as softskills de teamwork, troca de ideias, etc.
